Password di atas adalah nilai awal dari program. Admin dapat mengubah nama, username, atau password melalui menu **Kelola Sandi**. Perubahan tersebut disimpan di `localStorage` pada browser/perangkat yang digunakan; README ini tidak berubah otomatis.

> **Catatan keamanan:** Aplikasi ini menyimpan akun di sisi browser dan cocok untuk demo atau penggunaan lokal. Jangan gunakan password tersebut untuk akun penting atau mengandalkan mekanisme ini untuk keamanan produksi.
