# MABIDA Professional — Buku Induk Siswa

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Pilih role dan akun.
4. Masukkan password demo.
5. Login akan membuka dashboard sederhana.
